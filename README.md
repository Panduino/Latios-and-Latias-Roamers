# Latios + Latias Roamers

Add **Latias and Latios** as simultaneous roaming legendary Pokémon throughout Hoenn.

On the player's first trip from Littleroot Town onto Route 101, the Eon Pokémon appear together ahead of the player. Approach them and both react before splitting up and flying away, beginning their journeys across Hoenn.

From that point forward, **Latias and Latios roam independently at Level 50**. Each keeps its own HP and status between encounters, relocates after escaping, and remains active until caught. Catching one does not remove the other.

## Features

- Latias and Latios released together through a Route 101 encounter event
- Both roam Hoenn simultaneously and independently
- Level 50 roaming legendary encounters
- Persistent HP and status between encounters
- Each roamer relocates after escaping from battle
- Catching one leaves the other active
- Animated Untamed Advanced overworld sprites
- Compatible grouped-roamer support for other roaming legendary mods

## Requirements

- [Untamed Advanced](https://github.com/goldenroddeptstore/Untamed-Advanced)
- [Hoenn Journey](https://github.com/TheOriginalDrJ/Hoenn-Journey)

This mod is designed specifically for **Hoenn Journey** and restricts Latias and Latios to Hoenn routes.

## Installation

Install the required mods, then install **Latios + Latias Roamers** through G1R Deluxe's mod browser or import the mod ZIP manually.
